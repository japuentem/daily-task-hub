# ⚡ TaskMaster PRO

**TaskMaster PRO** es una herramienta de productividad personal diseñada para profesionales que necesitan gestionar sus tareas diarias, medir el tiempo invertido en cada actividad y generar reportes de rendimiento de forma sencilla y elegante.

## ✨ Características Principales

- **✅ Gestión de Actividades**: Crea, edita y organiza tus tareas con prioridades y categorías.
- **⏱️ Control de Tiempo**: Cronómetro integrado por tarea para medir exactamente cuánto tiempo dedicas a cada actividad.
- **📊 Dashboard de Estadísticas**: Visualiza tu productividad de los últimos 7 días y la distribución de tiempo por categoría mediante gráficos interactivos.
- **📝 Mural de Notas Rápidas**: Un espacio estilo "post-it" para anotar ideas o recordatorios al instante con códigos de colores.
- **⏲️ Método Pomodoro**: Temporizador Pomodoro integrado para mantener el enfoque y gestionar descansos.
- **📄 Reportes Profesionales**: 
    - Genera resúmenes de texto listos para copiar y enviar por chat o correo.
    - Exporta toda tu información a **Excel (XLSX)** con un solo clic.
- **🌙 Modo Oscuro/Claro**: Interfaz premium que se adapta a tus preferencias visuales.
- **🔄 Tareas Recurrentes**: Soporte para actividades que se repiten diariamente de forma automática.
- **💾 Persistencia Local**: Tus datos se guardan de forma segura en tu navegador y puedes exportar/importar copias de seguridad en formato JSON.

## 🚀 Tecnologías Utilizadas

- **Core**: HTML5 Semántico, CSS3 (Custom Variables, Flexbox, Grid) y JavaScript Moderno (ES6+).
- **Gráficos**: [Chart.js](https://www.chartjs.org/) para la visualización de datos.
- **Exportación**: [SheetJS](https://sheetjs.com/) para la generación de archivos Excel.
- **Fuentes**: Google Fonts (Inter).
- **Iconos**: Emojis nativos y símbolos vectoriales.

## 🛠️ Instalación y Uso

Este proyecto es una **Single Page Application (SPA)** serverless, por lo que no requiere instalación de dependencias pesadas ni base de datos.

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en cualquier navegador moderno (Chrome, Edge, Firefox, Brave).
3. ¡Empieza a organizar tu día!

> [!TIP]
> Para una mejor experiencia, te recomendamos usar el **Modo Oscuro** (activable desde el icono de la luna en la navegación).

## 🔒 Privacidad y Datos

Todos tus datos se almacenan localmente en el `localStorage` de tu navegador. La aplicación no envía información a servidores externos, garantizando la privacidad de tus actividades y notas.
