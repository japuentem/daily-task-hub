# Reglas de Proyecto: Daily Task Hub

- **Mantenimiento de Documentación:** Siempre que realices un cambio funcional importante, añadas una nueva característica, modifiques la interfaz de usuario, o alteres la arquitectura del proyecto, debes actualizar el archivo `PROYECTO.md` para reflejar estas modificaciones. Asegúrate de mantener el formato y de colocar la nueva funcionalidad en el módulo correspondiente o crear uno nuevo si es necesario.
